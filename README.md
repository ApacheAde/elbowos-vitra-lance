# Vitra Lance

Full-colour Python 3 neon stained-glass harpoon arcade for ElbowOS.

Aim a glass lance up a vertical kiln.
Shatter teal / rose / amber / violet orbs.
Same-hue neighbours chain-pop.
Crimson slag orbs that reach the dais cost a heart.
A / D or arrows steer. Mouse aims. Space or click fires.

## Play

```
pip install -r requirements.txt
python3 vitra_lance.py --play
```

Source also mirrored as a distinct pack:
